# INSURE ONE — ชุดเริ่มต้นเว็บไซต์ (ภาษาไทย)

เว็บไซต์นี้เป็น **ต้นแบบสำหรับพัฒนาและทดสอบ** ไม่ใช่ระบบขายประกันพร้อมใช้งานจริงในทันที

## มีอะไรในชุดนี้
- หน้าแรก responsive สำหรับมือถือและคอมพิวเตอร์
- หน้าต้นแบบเข้าสู่ระบบ / สมัครสมาชิก
- หน้ารายการผลิตภัณฑ์และแบบฟอร์มขอใบเสนอราคา (ยังไม่บันทึกข้อมูล)
- โครงสร้างฐานข้อมูล Supabase เบื้องต้น
- โครงร่างสำหรับต่อยอดระบบสมาชิก, หลังบ้าน, คำขอซื้อ, ชำระเงิน และกรมธรรม์

## ต้องเตรียมอะไร
- Node.js รุ่น LTS
- บัญชี GitHub
- บัญชี Supabase
- บัญชี Vercel (สำหรับเผยแพร่เว็บไซต์)

## ทดลองบนคอมพิวเตอร์
1. ติดตั้ง Node.js LTS จาก https://nodejs.org/
2. แตกไฟล์ ZIP นี้
3. เปิด Terminal หรือ Command Prompt ในโฟลเดอร์ `insure-one-starter`
4. รัน `npm install`
5. คัดลอก `.env.example` เป็น `.env.local`
6. ยังไม่ต้องใส่คีย์ใด ๆ เพื่อทดลองหน้าเว็บต้นแบบ
7. รัน `npm run dev`
8. เปิด `http://localhost:3000`

## ต่อฐานข้อมูล Supabase (ขั้นทดสอบ)
1. สร้างโปรเจกต์ทดสอบใน Supabase
2. เปิด SQL Editor แล้วรันเนื้อหาใน `supabase/schema.sql`
3. คัดลอก Project URL และ publishable/anon key จากหน้า Project Settings มาใส่ `.env.local`
4. **ยังไม่มีการเชื่อมระบบสมัครสมาชิกหรือบันทึกแบบฟอร์มในโค้ดนี้** ต้องพัฒนาต่อพร้อมทดสอบ RLS และสิทธิ์เข้าถึงก่อนใช้ข้อมูลจริง

## เผยแพร่บน Vercel
1. สร้าง repository ใหม่บน GitHub และอัปโหลดไฟล์โครงการ
2. เข้าสู่ Vercel แล้วเลือก Add New Project และนำเข้า repository
3. ตั้งค่า environment variables เฉพาะที่จำเป็น
4. Deploy และทดสอบหน้าเว็บบนมือถือ/คอมพิวเตอร์
5. ใช้โดเมนฟรีที่แพลตฟอร์มให้ในช่วงทดลองได้ โดยตรวจสอบเงื่อนไขปัจจุบันของผู้ให้บริการ

## ก่อนเปิดขายจริง ต้องทำเพิ่ม
- เชื่อม Supabase Auth จริง: สมัคร, เข้าสู่ระบบ, ออกจากระบบ, รีเซ็ตรหัสผ่าน และยืนยันอีเมล
- สร้าง server endpoints สำหรับแบบฟอร์ม, คำสั่งซื้อ, webhook และผู้ดูแล
- ทำ Admin dashboard และ role-based access control
- เพิ่มการจำกัดคำขอ (rate limiting), validation, logging, backups และทดสอบความปลอดภัย
- ใช้ผู้ให้บริการชำระเงินที่อนุมัติธุรกิจ/รูปแบบการขายประกันของคุณ และยืนยันยอดจาก webhook ฝั่ง server
- ไม่เก็บข้อมูลบัตรเครดิตหรือข้อมูลธนาคารของลูกค้าเอง
- เชื่อมข้อมูลผลิตภัณฑ์จากแหล่งที่ได้รับอนุญาต ระบุวันที่ตรวจสอบและวันหมดอายุราคา
- ยืนยันกับบริษัทประกันและ คปภ. ว่าการเสนอขาย/รับชำระเงินออนไลน์และบทบาทของผู้ขายทำได้ตามสิทธิ์ที่มี
- จัดทำนโยบายความเป็นส่วนตัว, เงื่อนไขบริการ, การเก็บรักษา/ลบข้อมูล และช่องทางใช้สิทธิของเจ้าของข้อมูล
- อย่าใส่ข้อมูลลูกค้าจริงในระบบทดสอบ

## ความปลอดภัยสำคัญ
- ห้ามเผยแพร่ Supabase service-role key หรือ payment secret key ใน browser หรือ repository
- ห้ามให้ผู้ใช้ทั่วไปแก้ราคา สถานะชำระเงิน หรือสถานะกรมธรรม์
- ห้ามตั้งสถานะ `paid` จากการอัปโหลดสลิปอย่างเดียว ให้ยืนยันจากผู้ให้บริการชำระเงิน
- ห้ามแสดงผลิตภัณฑ์เป็นซื้อออนไลน์ได้จนกว่าจะยืนยันสิทธิ์และขั้นตอนกับบริษัทที่เกี่ยวข้อง

## บริษัทประกัน
เพิ่มเฉพาะชื่อผลิตภัณฑ์และรายละเอียดที่คุณได้รับอนุญาตให้ใช้และเผยแพร่ เช่น ผลิตภัณฑ์ที่เกี่ยวข้องกับ Samsung Life Insurance และอินทรประกันภัย หลังยืนยันชื่อทางการและสิทธิ์การเสนอขายแล้ว
